# invest-website

Minimal static placeholder site for GitHub Pages.

## Files

- `index.html` is the published page.
- `404.html` keeps missing pages plain.
- `robots.txt` and the `noindex` meta tag ask crawlers not to index the site.
- `.nojekyll` tells GitHub Pages to serve the files directly.

## Custom Domain

After DNS is ready, add a `CNAME` file containing the domain name and configure
the same custom domain in the GitHub Pages settings for this repository.
